本書のモデルは固定係数の学習用スコアです。確率ではなく、機械学習で係数を推定したモデルでもありません。

score = 艇番基礎点 + 50 × win_rate + 20 × motor_rate

艇番基礎点は1〜6号艇で40,20,15,12,8,5です。同点なら艇番の小さい方を選びます。入力のwin_rateとmotor_rateは0〜1の教材用指標です。
```bash
boatoz predict data/sample_races.csv
```
検証はレースごとに最高スコアの艇を選び、実際に1着だった割合を計算します。6艇の確定着順が揃わないレースは全体を除外し、除外件数も報告します。対象0レースの精度はnullです。

比較対象として「常に1号艇」の的中率も出力します。複雑な式でも単純な基準を上回らなければ、追加した仕組みの有用性は示せません。教材36レースは小さく、しかも架空なので実運用性能を示しません。

実データではレースより前に利用可能だった特徴だけを使います。過去成績と出走表を結合するなら、選手IDだけでなく集計の基準日時も管理し、将来の結果が混入しないようにします。
