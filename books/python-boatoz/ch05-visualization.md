散布図で横軸にモーター2連対率、縦軸に着順を置きます。着順は1が良い成績なので縦軸を反転します。
```bash
boatoz plot data/sample_races.csv --output output/motor-scatter.png
```
横軸は0〜1の割合です。公式データの40%を取り込む際は0.40へ変換します。図を見る前に単位を揃えてください。

点が重なるので透明度を下げています。同じ着順は離散的な値で、連続量のように細かな差があるわけではありません。相関係数は `df[["motor_rate", "rank"]].corr()` で確認できますが、相関は因果関係の証明にはなりません。選手の構成や会場の違いも影響し得ます。

教材のmotor_rateは乱数で作っているため、強い相関を期待する根拠がありません。練習：点の分布を見てから相関係数を確認し、図と数値の両方で説明してください。結果JSONだけをCSV変換した表にはmotor_rateがないので、この図には別途出走前データの結合が必要です。
