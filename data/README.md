# データの扱い
`sample_races.csv` は乱数シード42で作成した216艇・36レースの**架空教材データ**です。
氏名・番号・日付・能力値は実在の成績を示しません。`win_rate` は教育用の正規化指標、
`motor_rate` は0〜1の架空2連対率で、公式の勝率（得点平均）とは異なります。

実データは `boatoz download` で各自取得します。取得先は非公式のコミュニティAPI:
https://github.com/boatraceopenapi/results （results/v3）。第三者データには提供元の条件が適用され、
本リポジトリのBSDライセンスによって第三者データの利用許諾が与えられるわけではありません。
全国日次は `data/raw/YYYY-MM-DD.json`。参照元の `data/raw/tsu/*.json` もparseに渡せます。
結果JSONだけでは事前の勝率・モーター2連対率は取得できません。これらを0で補完しません。
実データでモデルを使う場合は、レース前に公開された出走表を別途取得・照合してください。
