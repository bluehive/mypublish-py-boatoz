変数は値に付ける名前です。リストは複数の値、辞書は項目名と値をまとめます。インデントは処理のまとまりを示します。
```python
ranks = [1, 3, 2, 6]
racer = {"name": "架空選手", "ranks": ranks}


def mean(values):
    return sum(values) / len(values)


print(racer["name"], mean(racer["ranks"]))
```
平均着順は3.0になります。空のリストは0件なので割り算できません。入力の前提を確かめる習慣を付けましょう。

ボートレースは通常6艇で行われ、艇番と進入コースは別の概念です。1着率は「1着回数÷有効な出走数」、2連対率は「1着または2着の回数÷有効な出走数」です。公式の勝率は得点の平均であり、1着率とは異なります。

練習：リストに2を追加して平均を計算してください。答えは2.8です。まとめると、値を表す、手順を書く、結果を確認する、の3段階が基本です。
